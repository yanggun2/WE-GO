# 🏠 가구 쇼핑몰 웹사이트 (이가구 - igagu)

## 📌 프로젝트 개요
2학년 2학기 캡스톤디자인 수업
이 프로젝트는 사용자가 다양한 가구를 검색하고, 상품 상세 정보를 확인하며, 장바구니에 추가 및 구매할 수 있는 **가구 쇼핑몰 웹사이트**입니다.  
관리자는 공지사항을 작성하고 상품을 관리할 수 있으며, 사용자는 로그인 후 주문 및 혜택을 확인할 수 있습니다.

---

## 🚀 주요 기능
### 1️⃣ **사용자 기능**
- 🔍 **상품 검색 및 상세 조회**: 다양한 카테고리별 상품을 확인하고, 상세 정보 페이지에서 옵션을 선택 가능.  
- 🛒 **장바구니 및 결제**: 원하는 상품을 장바구니에 추가하고 구매 진행.  
- 📢 **공지사항 및 고객센터**: 공지사항 확인, FAQ 조회 및 1:1 문의 가능.  

### 2️⃣ **관리자 기능**
- ✏️ **공지사항 관리**: 공지사항 작성, 수정, 삭제 가능.  
- 🏬 **상품 관리**: 새로운 상품 추가 및 기존 상품 정보 수정 가능.  

### 3️⃣ **인증 시스템**
- 🔑 **회원가입 및 로그인**: 사용자 정보 입력 후 로그인 가능.  
- 🛠️ **관리자 권한 부여**: `admin` 계정으로 로그인 시 관리자 기능 활성화.  

---

## 🛠️ 기술 스택
- **Frontend**: HTML, CSS, JavaScript  
- **Backend**: PHP, MySQL  
- **Database**: MySQL  
- **Version Control**: Git, GitHub  

---

## 📂 프로젝트 구조
- 업로드 된 폴더 확인

---

## 🔧 실행 방법
### 1️⃣ **로컬 환경에서 실행**
1. XAMPP 또는 MAMP와 같은 **로컬 서버 환경**을 준비합니다.
2. MySQL에서 `igagu` 데이터베이스를 생성하고, `products` 및 `users` 테이블을 설정합니다.
3. 프로젝트 루트를 웹 서버 디렉토리 (`htdocs` 또는 `www`)에 배치합니다.
4. `http://localhost/index.html` 로 접속하여 실행합니다.

# ✈️ 맞춤형 여행 웹사이트(위고 - We-Go)

## 📌 프로젝트 개요
3학년 1학기 프로젝트구현 수업
이 프로젝트는 여행을 사랑하는 MZ세대와 외국인 관광객을 대상으로,
사용자가 원하는 맞춤형 여행 정보를 제공하는 여행 웹사이트입니다.
사용자는 다양한 여행지를 검색하고, 상세 정보를 확인하며, 리뷰 작성과 커뮤니티 활동이 가능하고,
관리자는 게시글, 공지사항, 여행 콘텐츠 등을 관리할 수 있습니다.

🚀 주요 기능
### 1️⃣ **사용자 기능**
- 🔍 **여행지 검색 및 상세 정보 조회**: 다양한 카테고리별로 여행지를 검색하고, 상세 페이지에서 숙박, 맛집, 액티비티 등 추가 정보를 확인합니다.
- 🗺️ **맞춤형 여행 추천**: 사용자의 선호와 검색 이력을 기반으로 맞춤형 여행지를 추천합니다.
- 📄 **여행 리뷰 및 커뮤니티**: 사용자가 여행 후기를 남기고, 다른 사용자와 정보를 공유할 수 있습니다.
- 📢 **공지사항 및 고객센터**: 최신 공지사항, FAQ 조회 및 1:1 문의 기능을 제공합니다.

### 2️⃣ **관리자 기능**
- ✏️ **콘텐츠 관리**: 여행지 정보, 리뷰, 공지사항 등의 작성, 수정, 삭제 기능.
